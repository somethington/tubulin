WHY KINESIN

A thin, fast layer between your analysis and the browser.

Declarative widget tree
Describe the UI as a node tree; the server diffs and pushes updates over WebSocket. No render loops, no manual state plumbing.
Rust runtime
A compiled core handles sessions, streaming and large frames — so dashboards stay responsive as your data grows from megabytes to gigabytes.
Theme-first CSS
Hand-written, dependency-free CSS driven entirely by custom properties. Restyle the whole app — light or dark — by editing tokens.
AUTHOR IN PYTHON

If you can write a script,
you can ship an app.

Inputs read like variables, outputs render in place. Kinesin handles the reactive graph, the transport, and the rendering.

✓Hot-reload on save, state preserved
✓Streaming job logs & progress out of the box
✓Plotly, tables & galleries built in
app.py 
import kinesin as kn

kn.header("Differential expression")

genome = kn.select("Reference", ["hg38", "mm10"])
threads = kn.number("Threads", value=16)

if kn.button("Run pipeline"):
    job = run_deseq2(genome, threads)
    kn.job_status(job)          # live progress
    kn.table(job.results)
    kn.download(job.csv)
